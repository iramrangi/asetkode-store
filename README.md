## Architecture & Store Features

- **Cloudflare Pages Edge Hosting** with strict security headers (`_headers`), bilingual localized routes (`/` and `/en/`), and XML sitemap coverage (`sitemap.xml`).
- **Dual Checkout Routing:** Instant QRIS / Mayar IDR workflow for domestic buyers and automated Polar.sh USD checkout for global cards & Apple Pay.
- **24/7 Automated Delivery:** Google Apps Script backend verifies `order.paid` webhooks and dispatches Google Drive `.ZIP` packages directly to customer email.
